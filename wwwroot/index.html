🗺️ Ala Wiki Mind Maps

Visualize your Git-based wiki as interactive mind maps

Getting Started:
  1. Configure your Git repository path in appsettings.json
  2. Select a markdown file from the dropdown
  3. Click "Load Mind Map" to visualize the heading hierarchy
  4. Or click "Load All Files" to see all wiki pages in one view
